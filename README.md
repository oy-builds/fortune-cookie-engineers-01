# Fortune Cookie Funnies for Engineers

A make.fun entry for **Fortune Cookie Funnies for Engineers**: one original
fortune-cookie line for a software engineer, 120 characters or fewer.

`main.ts` (Node 22, zero dependencies) writes the line to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), validating the
kit gate first: UTF-8, 1–120 characters, not only whitespace, single line.

The fortune:

> You will fix a bug today that you wrote last year at 2 a.m. — and you will do it again.

Run it with `node main.ts`.
